Stable Diffusion 实战：从文生图到图生图 ​

上一篇我们聊了 Diffusion 怎么“猜”出一张图。今天这篇更接地气：怎么把这套原理变成你能操控的工具。

一、Stable Diffusion 不是“一个模型”，而是一套流水线 ​

很多刚接触 AI 画图的同学会以为，Stable Diffusion 就是一个“输入文字、输出图片”的黑盒。其实它更像一条流水线，由好几个模块分工协作。

你可以把它想象成一家餐厅：

  • 文本编码器（Text Encoder / CLIP） 是“服务员”，负责把你的 Prompt 翻译成后厨能听懂的“订单”。
  • U-Net 噪声预测网络 是“主厨”，负责真正的去噪工作，一步步把噪声变成图像。
  • VAE（变分自编码器） 是“传菜员”，负责在“像素世界”和“潜空间世界”之间来回搬运。
  • 采样器（Sampler） 是“火候控制”，决定每一步去噪迈多大、走多少步。

你输入一句“一只橘猫在沙发上”，CLIP 先把这句话变成一个向量；U-Net 拿着这个向量，在潜空间里一点点擦掉噪声；VAE 最后把潜空间的结果解码成你能看到的 PNG。

理解这条流水线很重要，因为后面讲的 ControlNet、LoRA、图生图，都是在这条流水线的某个环节“动动手脚”。

二、文生图：Prompt 就是你的遥控器 ​

文生图是最基础的功能。你给一段文字，模型给你一张图。但同样是“一只橘猫在沙发上”，不同人写出来的 Prompt，效果可能天差地别。

Prompt 为什么重要？ ​

因为模型对文字的理解，和你对文字的理解，不在同一个频道上。

你写“一只猫”，模型知道“猫”这个概念；你写“橘猫”，它知道“橘色+猫”；你写“毛茸茸的橘猫，午后阳光，坐在米色沙发上，85mm 镜头，柔和光影”，它就能画出一张更有“镜头感”的图。

Prompt 工程在图像生成里比在大语言模型里还重要。大语言模型至少能靠上下文“猜”你的意图；图像模型不会猜，它只会严格按照你给的描述去生成。

一个 Prompt 的基本结构 ​

你可以把 Prompt 拆成几层：

  1. 主体：谁/什么？（一只橘猫）
  2. 环境：在哪？什么氛围？（米色沙发上，午后阳光）
  3. 风格：什么画风？（写实照片、赛博朋克、水彩、宫崎骏动画）
  4. 质量词：提升画面质量的关键词（高细节、8K、专业摄影、景深）
  5. 负面提示词（Negative Prompt）：你不想要的（模糊、多余的手指、低质量、变形）

负面提示词特别值得一提。图像模型生成人手、文字、多肢体时很容易翻车，所以在 Negative Prompt 里写“bad anatomy, extra fingers, blurry, low quality”已经成了标配。

打个比方：Prompt 像是你给化妆师写的需求清单，正面清单写“要什么”，负面清单写“不要什么”。清单越清晰，成品越接近你想要的样子。

三、图生图：给模型一张“草稿” ​

文生图的问题是随机性太强。你写了一堆 Prompt，模型还是可能画出构图、姿态、风格都不对的图。

图生图（Image-to-Image）就是来解决这个问题的。你给模型一张参考图，模型在这张图的基础上重新生成。

怎么理解图生图？ ​

你可以把它想象成“让 AI 照着你的草图再画一版”。你画一个火柴人，AI 帮你画成精美的插画；你拍一张照片，AI 帮你转换成动漫风格。

技术上，图生图其实是这样工作的：

  • 先把你的参考图编码到潜空间
  • 然后往潜空间里加一些噪声（加多少由 Denoising Strength / 重绘幅度 控制）
  • 再让模型根据 Prompt 去噪，生成新的图

重绘幅度是关键参数：

  • 数值越小（比如 0.2），生成的图越像原图，只是稍微润色
  • 数值越大（比如 0.8），生成的图越自由，可能只保留了大致构图

打个比方，重绘幅度就像是你让画师临摹一幅画的“自由发挥程度”。0.2 是“尽量像原图”，0.8 是“参考一下构图，剩下的你自由发挥”。

四、ControlNet：让模型“听话”的缰绳 ​

文生图和图生图解决了“画什么”和“参考什么”的问题，但还不够精确。比如你想让生成的人物保持某个姿势、让建筑保持某个透视、让线条遵循某个草图——这就需要 ControlNet。

ControlNet 是什么？ ​

简单说，ControlNet 是在 Stable Diffusion 的 U-Net 旁边“再接一个小网络”，这个小网络专门负责理解你给的控制条件，然后把控制条件注入到去噪过程中。

你可以把它想象成骑马时的缰绳。没有缰绳，马会乱跑；有了缰绳，你可以控制方向、速度、转弯。ControlNet 就是你握住的那根缰绳。

常见的 ControlNet 类型 ​

类型控制什么类比
OpenPose人物姿态、骨架让模特摆好姿势再拍照
Canny / Lineart边缘线稿给画师一张线稿让他上色
Depth深度图、远近关系先定好场景的 3D 结构
Scribble涂鸦草图随手画个草稿让 AI 细化
Normal Map表面法线、凹凸感告诉模型物体表面朝向
Segmentation语义分割指定“这块是天空，这块是草地”

最常用的是 OpenPose 和 Canny。

OpenPose 可以从一张真人照片里提取出骨架图，然后你让模型根据这个骨架生成新的人物。这样就能保证人物的姿势、手势、站姿完全一致。

Canny 边缘检测可以提取出图的轮廓线，然后你让模型“照着这个轮廓重新画”。这在做风格迁移、线稿上色时特别好用。

ControlNet 的工作流程 ​

  1. 你准备一张参考图
  2. 用预处理提取出控制信息（骨架、边缘、深度等）
  3. 把这个控制信息交给 ControlNet
  4. Stable Diffusion 在生成时，既参考你的 Prompt，也参考控制信息
  5. 最终输出的图在结构上“听话”，在内容上由 Prompt 决定

打个比方：ControlNet 像是你请了一个严格的导演。你说“拍一部科幻片”（Prompt），导演说“但是演员必须站在这个位置、这个姿势、这个构图”（ControlNet）。最后拍出来的，既是你想要的题材，又符合你的分镜要求。

五、LoRA：给 Stable Diffusion 换“风格镜头” ​

上一篇讲大模型微调时我们聊过 LoRA。在图像生成里，LoRA 同样大放异彩。

图像领域的 LoRA 是干嘛的？ ​

Stable Diffusion 的基础模型（比如 SD 1.5、SDXL、Flux）已经学会了“怎么画图”，但它不一定擅长画某种特定风格、特定角色或特定物品。

LoRA 的作用就是：在不改动基础模型的情况下，教模型一种新风格、新角色或新概念。

你可以把它想象成相机的可换镜头：

  • 机身（基础模型）不变
  • 换个镜头（LoRA），就能拍人像、拍风景、拍微距

常见的 LoRA 类型 ​

  • 风格 LoRA：让模型学会某种画风，比如“吉卜力动画风”“赛博朋克霓虹风”
  • 角色 LoRA：让模型稳定画出某个特定人物，保持面部、服装、发型一致
  • 物品 LoRA：让模型画出某款产品、某个道具，保持外观一致
  • 概念 LoRA：比如“水墨山水”“像素游戏”“低多边形 3D”

为什么 LoRA 在图像圈这么火？ ​

因为训练一个完整的 Stable Diffusion 模型需要海量数据和算力，但训练一个 LoRA 只需要几十张图、一块消费级显卡、十几分钟到几小时。

而且 LoRA 文件通常只有几十到几百 MB，方便分享、加载和切换。Civitai、Hugging Face 上有大量社区训练的 LoRA，下载下来就能用。

使用 LoRA 的小技巧 ​

  • 权重（Weight）：控制 LoRA 的影响强度。太低没效果，太高会把原图风格“压过去”，通常 0.6~1.0 之间摸索。
  • 多个 LoRA 叠加：可以同时加载多个 LoRA，比如一个角色 LoRA + 一个风格 LoRA。但叠加太多容易冲突，建议先试两个。
  • 触发词（Trigger Words）：很多 LoRA 需要你在 Prompt 里写特定的触发词才会生效，训练者通常会写在说明里。

六、实战组合：如何用这些工具画一张可控的图 ​

真正好用的工作流，往往是把文生图、图生图、ControlNet、LoRA 组合起来。

举个例子：你想画一张“穿着红色连衣裙的女孩站在樱花树下”的动漫风格图，并且姿势要和你提供的一张参考照片一致。

一个典型的流程是：

  1. 用 OpenPose 提取参考照片的姿态，得到骨架图
  2. 加载一个动漫风格 LoRA，让整体画风偏向动漫
  3. 文生图阶段：写 Prompt“女孩，红色连衣裙，樱花树，春天，动漫风格”，同时启用 ControlNet OpenPose
  4. 初步结果不满意？ 把结果送到图生图，调低重绘幅度，优化细节
  5. 还想换画风？ 换一个风格 LoRA，再跑一遍

你看，这不像是在“让 AI 画画”，更像是在指挥一个 AI 画室：你负责定方向、定姿势、定风格，AI 负责执行。

七、前端同学能怎么玩？ ​

作为前端开发者，你可能不会天天自己跑 SD，但理解这些概念能帮你做很多有趣的产品：

  • AI 头像生成器：用户上传一张照片，用 OpenPose + 风格 LoRA 生成动漫头像
  • 线稿上色工具：用户上传线稿，用 Canny ControlNet + 图生图自动上色
  • 商品图合成：用 Depth + Segmentation 控制构图，把商品放到指定背景里
  • 实时预览界面：结合 WebSocket 或 Server-Sent Events，展示生成进度
  • Prompt 模板库：给用户提供预设 Prompt，降低使用门槛

如果你有兴趣把 Stable Diffusion 接到前端，可以看看 ComfyUI（节点式工作流）、Automatic1111（经典 WebUI）、Stable Diffusion WebUI Forge（性能优化版）。它们都提供了 REST API，前端可以直接调用。

写在最后 ​

Stable Diffusion 的魅力在于：它不是一次性给你答案，而是给你一套可以反复调试的工具链。

Prompt 决定内容，ControlNet 决定结构，LoRA 决定风格，图生图决定迭代方向。把这四个旋钮配合好，你就能从“随机抽卡”进化到“精确创作”。

对于前端开发者来说，Stable Diffusion 更像是一个值得包装成产品的能力。理解它的每个模块，你才能设计出好用的交互、合理的参数面板、以及让用户有掌控感的生成流程。

下次看到别人晒 AI 美图时，你可以多想一层：这张图背后，是 Prompt 撑起了内容，还是 ControlNet 撑起了构图，又或者是 LoRA 撑起了风格？

看懂了这些，你就从“围观者”变成了“能用的人”。
