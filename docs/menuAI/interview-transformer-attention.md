今天先啃最硬的一块：Transformer 和注意力机制。

## 1. Q、K、V 分别是什么？整体逻辑是什么？

先记住一句话：**注意力机制的本质，是"让每个词去翻别的词，决定自己该吸收多少信息"**。

Q、K、V 是三个向量，你可以这么理解：

- **Q（Query，问题）**：当前这个词"想了解什么"。好比你脑子里蹦出的一个问题。
- **K（Key，钥匙/标签）**：每个词贴的一张"索引卡"，写着"我大概是关于什么的"。
- **V（Value，内容）**：每个词真正携带的"干货信息"。

整体逻辑画成图就是一条流水线：

1. 输入一句话，每个词先变成 Q、K、V 三个向量（靠三个不同的投影矩阵算出来）。
2. 拿当前词的 Q，去和**所有词**的 K 逐个做点积，得到一个"相关分数"——意思是"我和你有多搭"。
3. 把这些分数过一遍 softmax，变成加起来等于 1 的权重（谁更相关，权重就更大）。
4. 用这些权重，对所有词的 V 做加权求和。
5. 得到的新向量，就是"这个词看完上下文之后，更新过的理解"。

打个比方：你在一个满是人的房间里想找"会修水管的人"。你脑子里的问题是 Q（"谁懂水管？"），每个人胸前挂个标签 K（"我擅长做饭""我擅长电路""我擅长水管"），真正的能力是 V。你拿 Q 去比对每个人的 K，越匹配的你越认真听他讲（权重高），最后综合出"修水管该找谁"的结论。

说白了就是：**Q 问，K 答"我是谁"，V 给"实际内容"，按匹配度把 V 搅和到一起**。

## 2. 多头注意力的作用是什么？

单头注意力，相当于你只用**一个角度**看一句话。但一句话里的关系很复杂：有语法关系（主谓宾）、有指代关系（"它"指谁）、有语义关系（近义词）、还有位置关系。

多头注意力（Multi-Head Attention）就是：找**好几个人同时看**，每个人关注一个不同侧面。

类比看一幅画：一个人盯着整体构图，一个人看色彩搭配，一个人看笔触，一个人看明暗。最后把四个人的观察拼起来，你对这幅画的理解就立体了。

每个头在各自的"子空间"里算注意力，捕捉不同类型的关系。模型不需要你告诉它"第 3 个头负责指代"——它自己学。你只要给它足够多的头（比如 8 个、16 个、32 个），它就能分工合作。

## 3. 多头注意力里每个头是怎么工作的？

关键点是：**每个头有自己独立的一套小投影矩阵**（Wq、Wk、Wv），彼此不共享。

流程是这样的：

1. 输入进来的时候，每个头先用自己的 Wq/Wk/Wv，把输入投影到一个**低维子空间**（比如原本 512 维，8 个头每个头就分到 64 维）。
2. 在这个小空间里，该头独立完成标准的"Q·Kᵀ→softmax→乘 V"那一套。
3. 8 个头各算出一份结果。
4. 把 8 份结果**拼回**原来维度，再过一层融合矩阵 Wo，让头与头之间也能互通有无。

你可以理解为：8 个专家每人拿了一份缩减版的材料，在自己擅长的小本子上做笔记，最后把 8 本笔记订在一起，再由主编（Wo）统稿。

## 4. 为什么要对 QK 点积做缩放（除以 √d_k）？

不缩放会出事。点积是"对应维度相乘再相加"，维度 d_k 越大，点积结果的**方差就越大**——简单说就是数值会变得很大。

数值一大，丢进 softmax 会怎样？softmax 是个"赢者通吃"的函数，输入差异一大，输出就极度集中（某个接近 1，其余接近 0），梯度会逼近 0，模型就**学不动了**（梯度消失在 softmax 入口处）。

除以 √d_k 的作用，相当于把数值的"波动幅度"拉回到 1 附近，softmax 不会过早饱和，大家还有区分度。

类比考试：如果满分随题目数无限放大（10 题满分 1000 分，100 题满分 10000 分），所有人分数都堆在高位，拉不开差距；除以 √题数这种归一化，就是让分数回到合理区间，区分度才在。

## 5. 梯度消失、梯度爆炸产生的原因？有哪些解决手段？

这俩是深层网络的老毛病，根源都在**链式法则的连乘**。

- **梯度消失**：反向传播时梯度要一层层往回乘。如果每一层的梯度都小于 1（比如 sigmoid 在两端梯度≈0、或者权值初始化偏小），连乘下去越乘越小，传到前面几层时几乎为 0，前面层就训不动。表现：前面的层学不到东西。
- **梯度爆炸**：反过来，如果每层梯度都大于 1（权值初始化偏大），连乘下去指数级放大，参数直接飞了（NaN）。表现：loss 突然变 NaN、震荡不收敛。

解决手段，按常见程度排：

1. **残差连接（Residual / Skip Connection）**：这是 Transformer 的命根子。它给梯度修了一条"直通路"——`输出 = F(x) + x`，反向时梯度可以绕过 F 直接传到前面，不被连乘吃掉。类比：高铁除了普通轨道，还修了一条直达专线，信号（梯度）不至于在中间站全耗光。
2. **合理的初始化**：Xavier / He 初始化，让每层的输入输出方差平稳，别一上来就太大太小。
3. **归一化**：BatchNorm、LayerNorm，把每层激活值稳定在一定范围，缓解饱和。
4. **梯度裁剪（Gradient Clipping）**：训练时给梯度设个上限，超过就按比例缩回去，专治爆炸。
5. **换激活函数**：用 ReLU 及其变体代替 sigmoid/tanh，减少饱和区。
6. **控制深度 / 用合适的结构**：实在太深就靠上面几招顶着。

## 6. KV Cache 是什么？作用是什么？为什么能加速？

先想自回归生成的过程：模型是一个字一个字往外蹦的。每蹦一个新字，它都得"看一眼"前面已经生成的所有字。而"看"的过程，本质上就是算前面每个字的 K 和 V。

**KV Cache 就是把这些算过的 K、V 存起来，下次不用重算。**

类比：考试时你把参考资料用图钉钉在桌上。每答一题，你只翻"新增的那一页"，前面钉好的不用重新跑去图书馆借。如果不缓存，每答一题都得把整本资料从头翻一遍——前面答过的字，它的 K、V 又被白白重算一遍。

加速原理在数学上很清楚：

- 不缓存：生成第 n 个字时，要对前 n 个字全算 K、V，总计算量随长度平方增长，是 O(n²)。
- 缓存后：每个新字只算它自己的 K、V（O(1) 新增），历史的直接复用。

代价是**显存**——K、V 得一直占着显卡内存。所以 KV Cache 本质是"用显存换算力"，也是为什么长上下文特别吃显存。后面文章会讲 PagedAttention、MLA 这些优化显存占用的招。

## 7. LayerNorm 和 RMSNorm 的区别？

两者都是"归一化"，目标都是让每层输入分布稳定，但**算得不一样**。

**LayerNorm（层归一化）**：
对一个样本的所有特征维度，算均值和标准差，然后 `(x - 均值) / 标准差`，再乘可学习的增益 γ、加偏置 β。它需要算两个统计量（均值、方差），还有两个可学习参数。

**RMSNorm（均方根归一化，Llama、Qwen 等主流模型爱用）**：
只算**均方根** `RMS = √(mean(x²))`，然后 `x / RMS`，再乘增益。它**不减去均值**，也**没有偏置 β** 这一项。

区别一句话：LayerNorm 是"先把成绩按班级平均分拉平，再缩放"；RMSNorm 是"只管波动幅度有多大，不管平均分高低，直接缩放"。

为什么 RMSNorm 流行？因为它少算一次均值、少一组偏置参数，**计算更省、速度更快**，而效果几乎打平。在千亿参数的模型里，每少一步运算都是真金白银的加速。
